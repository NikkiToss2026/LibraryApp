Я Nikki Toss. Учусь в вузе на разработчика программного обеспечения — сайты, приложения под три платформы, игры. До этого окончил колледж по специальности «администратор баз данных», там же, на втором курсе, на дисциплине «Управление и автоматизация баз данных», и началось моё программирование. Пишу код с осени 2024 года.

Из технологий — только Python и веб (HTML/CSS/JS): намеренно не распыляюсь на другие стеки. Каждый новый проект начинаю с нуля, даже если в основе лежит чужая идея или исходник — адаптирую под себя, а не переиспользую как есть. В разработке для меня одинаково важны и сам процесс, и результат: ценю аккуратность и в коде, и в визуальном оформлении проекта.

Большую часть проектов делаю в паре с напарником по разработке — RoverGit. Познакомились на почве общих интересов к программированию и общих принципов в архитектуре и структуре кода, работаем вместе около полутора лет. Роли между нами не закреплены жёстко — умеем оба делать всё, распределение задач каждый раз зависит от того, у кого сколько свободного времени; решения по проекту принимаем, только когда хотят оба.

Этот репозиторий — пространство, где собираются наши с RoverGit готовые и развивающиеся проекты: разные темы, разный масштаб, но один и тот же подход — спроектировать архитектуру с нуля, довести до рабочего состояния и аккуратно оформить. Рассчитываю, что это будет полезно другим разработчикам схожего профиля и организациям, которым нужен понятный пример того, как мы работаем.

I'm Nikki Toss. Currently studying software development at university — websites, cross-platform applications, games. Before that I graduated from a technical college with a degree in database administration — that's where I wrote my first real code, in a database management course in my second year. I've been coding since autumn 2024.

My stack is deliberately narrow — Python and the web (HTML/CSS/JS), nothing else. Every new project starts from scratch, even when it's built on someone else's idea or source — I adapt it to my own approach rather than reuse it as-is. For me, both the process and the result matter equally: I care about the code being clean and the project looking good just as much.

Most of my work is done together with my development partner, RoverGit. We met over shared interests in programming and a shared approach to architecture and code structure, and we've been working together for about a year and a half. We don't have fixed roles — we can both do anything — task distribution depends on who has time at any given moment; project decisions only go ahead when both of us want them to.

This repository is where RoverGit and I collect our finished and ongoing projects: different topics, different scales, but the same approach — design the architecture from the ground up, get it working, and finish it properly. I hope it's useful to other developers with a similar focus, and to organizations looking for a clear example of how we work.
